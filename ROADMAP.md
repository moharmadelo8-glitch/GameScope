# GameScope — Future Roadmap

## Next priorities
1. **Upgrade Advisor** — identify likely bottlenecks and suggest compatible CPU, GPU or RAM upgrades using documented requirements.
2. **Build Planner** — assemble a PC from a CPU, GPU, RAM and storage list and check games before saving.
3. **Verified benchmark library** — show FPS only with a recorded source, game version, CPU, GPU, RAM, resolution and preset. Never derive FPS from generic hardware tiers.
4. **Hardware specification cards** — expose CPU cores/threads, socket, clocks and generation; GPU VRAM type, bus width and power; mobile SoC details when verified.
5. **Comparison filters** — show games common to both devices, different compatibility results or platform exclusives.
6. **Data freshness** — flag old entries, conservative legacy estimates and missing source details.

## Longer-term ideas
- Algerian PC price guide with DZD prices, seller/source links and last-checked dates.
- Saved build profiles and upgrade scenarios.
- PWA installability and offline data cache.
- Reviewed community corrections through GitHub issues or pull requests.
- Personalized game discovery and game-update tracking.
- Low-end PC mode for 2 GB/4 GB RAM, integrated graphics and older CPU generations.
- Laptop GPU profiles distinct from desktop GPUs with similar names.

## Quality rules
- Keep English, Arabic (RTL) and French translations in sync.
- Support small screens and keyboard navigation.
- Treat missing information as **Insufficient Data**, never as a pass.
- Distinguish official requirements, conservative legacy estimates and community benchmarks.
- Never claim live prices, FPS or compatibility without supporting sources.
