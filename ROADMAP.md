# GameScope — Future Roadmap

This roadmap describes planned ideas, not features that are already available.

## Next priorities

1. **Upgrade Advisor** — identify the component most likely to limit a selected game's compatibility, then suggest compatible CPU, GPU or RAM upgrade paths. Recommendations must be based on documented requirements and clearly marked as estimates.
2. **Build Planner** — let users assemble a PC from a CPU, GPU, RAM and storage list, then check the planned build against the game library before saving it.
3. **Better comparison filters** — filter the comparison table to games available on both platforms, games with different compatibility results, or games exclusive to one platform.
4. **Verified benchmark library** — add FPS ranges only when a specific benchmark source, game version, resolution and graphics preset are recorded. Never generate FPS values from hardware tiers.
5. **More hardware coverage** — expand laptop GPUs, integrated graphics, older CPUs, Apple Silicon and additional mobile chipsets with clear source links.
6. **Game data freshness** — show a per-game verification date and a simple flag for entries that need source review.

## Longer-term ideas

- **Algerian PC price guide** with DZD prices, seller/source links and a last-checked date.
- **Saved build profiles** for multiple PCs and upgrade scenarios.
- **PWA support** for installability and offline access after the data has been cached.
- **Community corrections** through reviewed GitHub issues or pull requests; submitted data should not become trusted automatically.
- **Personalized game discovery** based on the user's saved devices, preferred genres and free/paid filters.
- **Game update tracker** for release changes and revised system requirements, using official publisher sources.

## Quality rules

- Keep English, Arabic (RTL) and French translations in sync.
- Keep the app usable on small screens and with keyboard navigation.
- Treat missing information as **Insufficient Data**, never as a pass.
- Distinguish official requirements from community benchmarks and estimates.
- Do not claim real-time prices, FPS or compatibility unless the data source supports that claim.
